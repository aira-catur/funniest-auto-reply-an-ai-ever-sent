# The Funniest Auto-Reply an AI Ever Sent

A deterministic Python entry for the [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) competition on make.fun. The program writes the entry text to `entry.txt`, with no trailing newline. The readable source is `entry_source.py`; `main.py` is the official make.fun compress output of that source.

## Running

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

If `MAKEFUN_OUTPUT_DIR` is not set, the entry is written to `/output/entry.txt`.
